## B 稳定性

- 保存时校验载入时的 main 提交及作品 JSON SHA，防止仅媒体变动或文案变动被旧页面覆盖。
- 媒体和 JSON 暂存为一个 Git tree/commit，最后 `force: false` 更新 main。上传失败不发布部分内容；保存过程的竞态不强推。
- 新 id 与 JSON/远端媒体目录冲突时阻止保存；已有 id 固定；只上传封面的新增作品不再指向不存在的现场图。
- JPEG/MP4 扩展名、MIME、文件签名、空文件与 40MiB 网页大小限制校验；更大文件走 staging，本机仍受 GitHub 100MiB 限制。
- 切换、新增、重载、退出的未保存确认；保存期间锁定输入和导航；登录失败不进入编辑态，会话存储被禁用时显示错误。
- 本机发布脚本先预检全部文件，准备副本，再切换目录；捕获到异常会回滚。进程被强杀或断电时须人工检查保留的 `.publish-*` 恢复目录后再提交。
- 部署检查不再限定三个作品，允许后台新增；检查内容结构、唯一 id 和媒体文件。
- Magnet 动态切换 reduced-motion 后立即清零位移；AssetImage 换源后可重试。
